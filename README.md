# Aesthetic Aura Clinic Management System

A premium desktop application built with Electron, React, and SQLite for managing a clinic's patients, doctors, appointments, services, and billing.

## Features
- **Dashboard**: Overview of clinic statistics and activity.
- **Patient Management**: Complete record-keeping for patients.
- **Doctor Management**: Track doctors, departments, and availability.
- **Appointment Booking**: Streamlined scheduling system.
- **Billing & Invoices**: Generate and track payments for services and products.
- **Inventory Management**: Track clinic products and stock.
- **Employee & Expense Tracking**: Manage staff and operational costs.

## Development
To start the app in development mode:
```bash
npm start
```

## Production Build
To package the app for Windows:
```bash
npm run dist
```

## Technology Stack
- **Frontend**: React, Tailwind CSS, Lucide Icons, Framer Motion
- **Runtime**: Electron
- **Database**: SQLite (better-sqlite3)
- **Build Tool**: Vite, Electron Builder
